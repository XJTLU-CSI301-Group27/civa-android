# C-V01：库存后端基础实现

## 版本范围

实现 C 模块的库存后端业务，包括食材库存、分批保存、到期筛选、数量变动及菜谱食材匹配。
原始开发基于 `7508531`，本次接入主线 `a0943b1` 并保留 BD 现有功能；尚未包含原生冰箱界面。

## 较上一版的提升

原项目的 C 库存接口处于占位状态。本版接入真实数据处理和业务校验。

| 场景 | 上一版 | 本版提升 |
| --- | --- | --- |
| 录入食材库存 | C 接口尚未实现 | 保存标准食材、数量、单位、储存位置与到期日期 |
| 同种食材多次入库 | 无批次业务处理 | 分别保留各批数量及到期日期 |
| 查询临期、过期食材 | 无实际筛选 | 按家庭查询库存，并按到期状态筛选 |
| 消耗、丢弃、库存修正 | 无实际数量变动处理 | 校验用量、保存余额与变动记录，阻止负库存 |
| 重复提交、并发修改 | 缺少 C 业务校验 | 复用幂等与版本校验，防止重复扣减及覆盖更新 |
| 菜谱与库存匹配 | 匹配接口尚未实现 | 计算已有食材、缺少数量及优先使用的库存批次 |

## 代码改动

原始实现共21个文件发生变化，包含9个库存业务Java文件、4个库存测试文件，
以及占位路由、测试配置、契约说明和交接文档的配套调整。本版另附本 Markdown 版本说明。

- `server/src/main/java/edu/xjtlu/civa/server/inventory/`：库存保存、批次管理、数量变动、输入校验与菜谱匹配。
- `server/src/test/java/edu/xjtlu/civa/server/inventory/`：单元测试及真实数据库接口测试。
- `server/src/main/java/edu/xjtlu/civa/server/web/UnimplementedController.java`：移交已实现的 C 路由。
- `server/build.gradle`：纳入库存单元测试。
- `docs/C_HANDOFF.md`、`docs/DATA_CONTRACT.md`、`docs/TEST_PLAN.md`：开发说明、数据约定及验证记录。
- `contracts/changes/IC-9.md`：跨组批次分配入口提案，状态为 PROPOSED。

## 核心实现

- `InventoryService`：保存、查询批次，执行消耗、丢弃和数量修正。
- `InventoryRules`、`IngredientNames`：校验数量、日期及食材名称。
- `InventoryCalculator`、`InventoryMatchingService`：计算菜谱匹配、缺少数量及批次分配。
- `InventoryController`、`InventoryErrors`：接入库存接口并映射业务错误。
