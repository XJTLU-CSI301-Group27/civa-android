## 相较第四版的优化

| 场景 | 第四版 | 第五版 |
| --- | --- | --- |
| 英文候选提示 | 输入一个字符也可展开较多结果 | 输入至少两个字符才提供候选；直接输入完整名称仍可保存 |
| 搜索排序 | 按字典载入顺序展示 | 名称或别名前缀匹配优先，再按名称排序 |
| 名称格式 | 去首尾空白、忽略大小写及全角差异 | 进一步折叠连续空白，Fresh pear 等名称能稳定匹配 |
| 候选单位 | 中文单位文字 | 统一显示 g / ml / pcs；按钮左对齐、取消额外字距、单行省略 |
| 表单错误 | 修改内容后旧错误仍可能保留 | 输入名称、数量或日期，以及修改单位或位置后清除旧校验提示 |
| 单位与位置选择 | 输入变化可能重置新食材的单位或手选位置 | 保留未收录名称已选单位及合适的手选位置，减少重复选择 |
| 空名称 | 经后续逻辑返回错误 | 保存时明确提示请输入食材名称 |
| 数量超范围 | 较通用的校验异常 | 区分输入过大和 kg 换算后过大，提示减小数量 |
| 常见食材分类 | 覆盖基础英文名 | 增加 cheese、water、prawns、salmon、steak、sausages 等名称及复数 |
| 图标回退 | 部分食材落入通用蔬菜图标 | 根据蛋奶、水果、肉、海鲜分类选择相应回退图标；eggplant 不误判为蛋 |
| 状态与错误提示 | 可能显示读取批次数、内部错误代码和开发环境用语 | 清理占屏读取信息，网络或未知错误采用用户可理解的提示 |
| 预览环境 | 已有测试库与设备保护 | 再检查 APK 后端地址，防止 8081 专用回归包覆盖 8080 预览 |
| 历史测试食材 | 已有按所有权清理的工具 | 加入只读审计、显式修复和备份；只处理有创建证据且未被实际采用的 fixture |

## 最终保留的库存能力

- 冰箱外壳、冷藏与冷冻开关门、首屏等高布局及宽窄详情。
- 已有英文名称/别名直接录入，未收录名称经标准食材创建接口保存。
- 名称、数量、单位、位置及可空到期日；服务器记录入库时间。
- 同标准食材和单位汇总显示，点开保留各批入库时间、到期日及数量。
- 全部、未过期、临期和已过期筛选。
- 消耗、丢弃、修正和编辑；归零前确认，确认后隐藏用尽批次，后台记录保留。
- g / kg / pcs 输入，液体按条件提供 ml；kg 仅换算为 G，不把旧重量变为个数。
- 最近变动、权限、版本及幂等处理继续复用已有后端。
- 第一版提供的库存匹配和内部批次分配保留；最终做饭事务仍由 D/E 的公共接入负责。
